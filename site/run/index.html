Don't have repodock yet?

repodock is a free app that downloads GitHub projects, works out how to start them, and runs them from one window. It shows you every command before it runs.

Windows

Install it, then click the button above again.

Download repodock

Linux

Install with pipx, start repodock, and turn on "Open Run with repodock links" in its Settings.

pipx install git+https://github.com/UmutAlisoglu/repodock
