Name: Run with repodock
Category: Developer Tools

Short description (132 characters max):
Run any GitHub project with one click in repodock, and get the right download for your computer on release pages.

Full description:
Run with repodock adds two buttons to GitHub.

On every project page, "Run with repodock" opens the project in repodock, a free desktop app that downloads GitHub projects, works out how to start them and runs them from one window. repodock asks before it downloads anything, and shows you the exact command before anything runs.

On release pages, "Download for Windows" (or macOS, or Linux) points straight at the file that suits your computer, so you don't have to guess between a dozen files. That file is also marked in the list.

The extension needs no permissions, collects no data and makes no network requests. It only reads the GitHub page you are on.

repodock is free and open source: https://github.com/UmutAlisoglu/repodock

Privacy:
- Single purpose: add "Run with repodock" and "Download for your system" buttons to github.com pages.
- Permissions: none. The content script runs only on https://github.com/*.
- Data: none collected, stored or sent. No remote code.
- Privacy policy URL (if a store asks): https://github.com/UmutAlisoglu/repodock/blob/main/extension/README.md
